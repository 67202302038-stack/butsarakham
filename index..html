# วันที่ จังหวัด/พื้นที่ กลุ่มโรค/หมวดหมู่ จำนวน สถานะ หน่วยงาน/รายละเอียด
แสดง 0 รายการ ระบบจะอัปเดตข้อมูลอัตโนมัติจาก Google Sheet

ตั้งค่าแหล่งข้อมูล Google Sheets CSV

ต้องเป็นลิงก์ที่เผยแพร่ทางเว็บ (Publish to Web) ในรูปแบบ CSV เท่านั้น

วิธีเผยแพร่จาก Google Sheets:

  1. เปิดไฟล์ Google Sheets ของคุณ
  2. ไปที่เมนู File (ไฟล์) > Share (แชร์) > Publish to web (เผยแพร่ไปยังเว็บ)
  3. เลือก Sheet ที่ต้องการ และเปลี่ยนจาก Web page เป็น Comma-separated values (.csv)
  4. กด เผยแพร่ (Publish) แล้วคัดลอก URL มาวางในช่องด้านบน

คู่มือการนำขึ้น GitHub Pages (ภายใน 3 นาที)

💡 เหตุผลที่เหมาะสำหรับงานสาธารณสุข:

GitHub Pages ช่วยให้คุณเผยแพร่ Dashboard นี้ออนไลน์ได้ ฟรี 100% ไม่มีค่าเซิร์ฟเวอร์ ปลอดภัย และดึงข้อมูลสดจาก Google Sheets ของคุณได้ตลอดเวลา!

1

บันทึกโค้ดนี้เป็นไฟล์ index.html

เซฟโค้ดนี้ลงเครื่องคอมพิวเตอร์ของคุณ ตั้งชื่อไฟล์ว่า index.html

2

สร้าง Repository ใหม่ใน GitHub

เข้าเว็บ GitHub.com > กด New Repository > ตั้งชื่อ เช่น health-dashboard > เลือกเป็น Public > กด Create repository

3

อัปโหลดไฟล์ index.html

ในหน้า Repository ที่สร้างขึ้น กด uploading an existing file แล้วลากไฟล์ index.html ลงไป แล้วกด Commit changes

4

เปิดใช้งาน GitHub Pages

ไปที่เมนู Settings ของ Repository > เมนูด้านซ้ายเลือก Pages > ในหัวข้อ Build and deployment ให้เลือก Branch เป็น main (หรือ master) / root > กด Save

พร้อมใช้งาน!

รอประมาณ 1-2 นาที คุณจะได้ URL เช่น https://your-username.github.io/health-dashboard/ สามารถนำลิงก์นี้ไปส่งต่อหรือเปิดดูบนมือถือและสมาร์ตโฟนได้ทันที!
